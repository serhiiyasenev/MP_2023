# 🎓 MP_2023 Mentoring Program

This repository contains the full set of practical modules, solutions, and code examples from the **MP_2023 Mentoring Program**. The program is designed for software engineers seeking to boost their skills in advanced C#/.NET, distributed systems, concurrency, and practical DevOps.

---

## 🚀 About the Program

MP_2023 is a hands-on mentoring program aimed at raising the expertise of .NET developers through real-world scenarios, architectural challenges, and advanced programming tasks. Each module is focused on a specific area critical to modern backend and full-stack engineering.

---

## 📚 Modules Overview

- **01_Multithreading:**  
  Practice and patterns for safe parallel programming, tasks, threads, synchronization, locking, and concurrent collections.

- **02_AsyncAwait:**  
  Deep dive into asynchronous programming in C#. Best practices, pitfalls, continuations, and real-world async workflows.

- **03_RabbitMQ:**  
  Messaging basics, producer-consumer, durable queues, and integrating RabbitMQ into .NET solutions.

- **04_AnalyzingAndProfiling:**  
  Tools and techniques for profiling .NET applications, identifying bottlenecks, and improving performance.

- **05_LINQ:**  
  Advanced LINQ queries, custom operators, deferred execution, and optimization techniques.

- **06_Expressions:**  
  Working with Expression Trees, dynamic code generation, and building custom LINQ providers.

- **07_MaxPathSum:**  
  Algorithmic challenges, including tree path sum problems, recursion, and optimization solutions.

- **10_Deployment:**  
  Practical DevOps: Docker, deployment automation, and best practices for delivering .NET apps.

- **11_GOF_CuttingShape:**  
  Application of classic GoF (Gang of Four) design patterns to practical coding tasks and refactoring.
